# 交接和升级规则

升级不是放弃线索。当前操作者仍然是线索负责人，必须追踪结果。

## 升级给销售/负责人

适用于：特殊优惠、复杂价格谈判、合同/发票/对公付款细节不确定、高价值机构/企业客户、多人决策、重点客户停滞。

Template:

```text
【升级销售/负责人】
用户：
来源：
当前标签：
用户场景：
当前进展：
已发资料：
学习地址/案例示例观看/反馈：
用户原话：
卡点：
希望协助：报价/采购/异议/关键背书/其他
需要反馈时间：
当前责任人：
```

## 升级给产品

适用于：功能边界、定制流程、学习效果不匹配、影响成交的需求、品牌/域名权益确认。

```text
【升级产品】
用户：
业务场景：
用户想完成的任务：
当前替代方案：
需求/反馈原话：
是否影响成交：
相关课程/截图：
希望判断：现有能力能否满足/替代路径/是否进需求池
```

## 升级给技术

适用于：Skill 安装失败、授权失败、上传失败、发布失败、学习地址打不开、模型互动异常。

```text
【升级技术】
用户：
问题类型：Skill安装/授权/上传/发布/学习地址/模型异常/其他
操作步骤：
报错截图：
设备与浏览器：
账号信息：
课程链接/课程名称：
用户着急程度：高/中/低
需要反馈时间：
```

## 以下情况继续自己推进

- 用户只是询问基础产品价值、套餐方向或如何开始。
- 用户还没有完成首课体验的关键证明点。
- 用户只需要标准话术或资料。
- 用户处于常规 3/7/14 天待唤醒流程。
