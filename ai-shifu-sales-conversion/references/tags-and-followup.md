# 标签和跟进规则

只使用四类标签，保持足够简单，方便微信手动打标和协作。

## 标签

| 类型 | 可选标签 |
|---|---|
| 客群 | `客群-个人创作者`, `客群-老师`, `客群-教育机构`, `客群-企业培训`, `客群-待确认` |
| 需求 | `需求-做课提效`, `需求-提升交付`, `需求-减少答疑`, `需求-培训沉淀`, `需求-课程变现`, `需求-采购咨询`, `需求-待确认` |
| 进展 | `进展-未回复`, `进展-已沟通`, `进展-已注册`, `进展-已装Skill`, `进展-已生成课程`, `进展-已拿学习地址`, `进展-已看案例/示例`, `进展-套餐咨询`, `进展-已成交` |
| 跟进 | `跟进-重点跟进`, `跟进-后续跟进`, `跟进-待培育`, `跟进-待唤醒`, `跟进-暂时放弃`, `跟进-已成交服务` |

## 跟进判断

| 跟进标签 | 什么时候使用 | 动作 |
|---|---|---|
| `跟进-重点跟进` | 企业/机构用户 lead, asks procurement, has learning URL, has viewed case/example, asks package/procurement, clear purchase intent | Same-day 1:1 push; ask for next decision step; escalate only if needed |
| `跟进-后续跟进` | 有兴趣但还没到证明点，卡在注册/安装/生成/发布 | 3-5 天内推动首课体验的下一节点 |
| `跟进-待培育` | 需求不清、价值感不足、没有资料、不紧急 | 发送案例、群内容、回放或低压力价值内容 |
| `跟进-待唤醒` | 触达后未回复或停滞 | 使用 3/7/14 天轻触达 |
| `跟进-暂时放弃` | Explicit no need, low fit, repeated no reply after 14 days | Stop manual high-frequency follow-up; keep low-frequency content only |
| `跟进-已成交服务` | Paid | Start post-sale activation and success evidence collection |

## 最小协作字段

`昵称/微信, 来源渠道, 负责人, 客群标签, 需求标签, 进展标签, 跟进标签, 意向套餐, 学习地址, 最近沟通摘要, 下一步动作, 下次跟进时间`


注意：购买前不要求外部学习者验证。核心证明阶段标签使用 `进展-已看案例/示例` 和 `进展-已拿学习地址`。
