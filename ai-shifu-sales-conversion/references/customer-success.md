# 成交后客户成功

除非明确交接，否则成交人或线索负责人要继续负责买后激活。目标不是“已付款”，而是“付款后真正产出学习结果”。买后激活应使用 AI 师傅课程创作指导课：http://app.ai-shifu.cn/c/57b5dd9f3bb6478683ef7674403cefa4

## 0-1 天：开通确认

检查清单：

- 套餐已开通，用户能进入后台。
- 用户已收到购买后课程创作指导课： http://app.ai-shifu.cn/c/57b5dd9f3bb6478683ef7674403cefa4
- 用户了解剩余积分和套餐周期基础规则。
- First official course topic and source material are confirmed.
- Owner and deadline for first learning URL are set.
- If enterprise: confirm invoice/contract/corporate-payment progress if relevant.

Talk track:

```text
开通后我们先不追求一下做很多门课，先把第一门正式课跑通。你今天/明天先确定一份资料，我跟你一起盯到学习地址出来。
```

## 第 3 天：创课进度

目标：避免“买了但没用起来”。

检查：

- Has the user selected material?
- Has Skill generated the course draft?
- Is the user blocked by operation, content, or decision?

If no progress:

```text
我们先把范围缩小，不做完整大课。你发我一个章节、一页 SOP 或一个高频问题就行，先把第一条学习地址跑出来。
```

## 第 7 天：第一门正式课

目标：发布一门正式课程，并完成内部体验。

检查：

- Course created from real material.
- Learning URL published and opens.
- User/owner has learned through it once.
- Main adjustment points are recorded.

If not published by day 7, mark risk and escalate product/tech/owner depending on blocker.

## 第 15 天：第二门课或使用扩展

目标：从一个样例扩展到可复用场景，不增加外部试学复杂度。

推动其中一个动作：

- Make the second course.
- Turn the first course into a formal internal/external learning link.
- Identify next department/class/user group.
- 收集负责人反馈：哪里清楚、哪里需要微调、哪些内容可以复用。

Talk track:

```text
第一门课跑通后，接下来要验证能不能复用。你可以选两个方向：要么做第二门课，看制作是否可复制；要么把第一门课整理成正式学习链接，用在你的真实业务场景里。
```

## 第 30 天：扩展、案例或续费信号

检查：

- Has the user created more than one course?
- Are there real learners or employees using it?
- Is there a team/department that wants to expand usage?
- Is there a public/private case story worth collecting?
- Are credits enough for planned usage?

## 客户成功证据

`课程主题, 学习地址, 套餐, 使用资料类型, 是否看过指导课, 当前卡点, 关键反馈, 节省了什么, 下一门课, 是否可做案例, 是否有扩容/续费机会, 当前风险`

## 风险信号

出现以下情况需要升级：

- Customer paid but no one owns materials.
- 用户 7 天内无法发布课程。
- 用户反馈较差，并影响继续使用。
- Customer expects unsupported custom development.
- Key buyer loses confidence.
- 积分消耗超出预期，用户产生成本焦虑。
