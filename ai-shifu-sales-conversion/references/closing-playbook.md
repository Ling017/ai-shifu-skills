# 成交收口手册

当用户询问价格、已经看过案例/示例课、已有学习地址，或表现出购买意向时使用。

## 成交顺序

1. 确认证据：是否已看客户案例/示例课？是否已拿自己的学习地址，或已理解自己的课程可以怎么做？
2. 确认使用范围：课程数量、学习人数、阅读/听课模式、追问强度。
3. 确认购买路径：个人付款 / 公司采购 / 需要合同发票对公 / 需要上级汇报。
4. 推荐套餐方向。
5. 推动一个明确下一步：付款、预约演示、发采购信息、准备汇报样例、确认开通时间。

## 套餐方向

| 用户情况 | 套餐方向 | 收口话术 |
|---|---|---|
| 个人创作者/老师测试一门课 | ¥199/月基础版 试用后 | 先低门槛跑通第一门正式课，再决定是否扩大 |
| 只需要低成本维护或汇报样例 | 9.9 仅作为补充说明 | 这个不作为正式交付主推，只适合微调/汇报样例 |
| 小团队或中小机构，有稳定课程需求 | ¥8,000/年进阶版 | 适合先跨过试用阶段，跑一个可持续交付场景 |
| 需要品牌/域名权益的机构或企业 | ¥15,000/年高阶版 | 品牌 logo 和 URL/域名替换从这个档位开始 |
| 需要支持/培训的大型机构 | ¥30,000/年旗舰版 | 更适合有实施节奏、支持和培训要求的团队 |

## 异议处理

| 用户异议 | 应对策略 | 可复制回复 |
|---|---|---|
| 太贵了 | 回到使用范围和证据 | 如果只是试一门课，不建议一上来买年套餐；可以先用 ¥199/月跑通正式课。如果是机构稳定交付，才看 8000/15000 年套餐。关键是先确认这条学习地址能不能带来真实交付价值。 |
| 我再看看 | 给一个具体查看任务 | 可以，你不用看很多资料。建议只看两个东西：一个客户案例看结果是否被验证，一个示例课看个性化学习是什么效果。看完后我们再判断你的产品/课程适合怎么做。 |
| 要内部讨论 | 给可汇报证据 | 内部讨论最好不要只拿价格表。你可以带三样东西：客户案例、个性化学习示例课、套餐对比。我可以帮你整理成给上级看的版本。 |
| 担心学员不用 | 从体验章开始 | 不建议一开始押完整大课。先做 5-10 分钟体验章，看学员是否愿意继续学、是否会追问，再决定是否扩大。 |
| 不确定人数够不够 | 解释估算口径 | 官网人数是基于约 10 节/100 分钟的估算，实际和课程长度、追问、模型、听课语音有关。我们先按你的首门课体量估算，不能承诺固定人数。 |
| 能不能优惠 | 守住统一口径 | 发布会权益会按统一口径来，我不能提前承诺具体折扣。现在更重要是先确认你适合哪个套餐，避免为了优惠买错档位。 |
| 能不能定制 | 先确认，不承诺 | 可以先记录你的场景和目标，但我不直接承诺开发排期。我们先看现有能力能否用替代路径满足；如果影响采购，再升级产品/负责人确认。 |
| 企业安全 | 建议脱敏试点 | 如果资料敏感，建议先用脱敏材料做试点。涉及权限、数据、安全和协议要求，可以进入企业合作流程单独确认。 |

## 成交追问

- 如果案例和示例课你认可，下一步是个人直接开通，还是需要走公司采购？
- 你希望什么时候正式上线第一门课？我按这个时间倒推开通和制作节奏。
- 你们内部决策还需要谁看？他最关心效果、价格、品牌、还是采购流程？
- 如果需要我帮你准备给上级看的材料，我建议放：客户案例、个性化学习示例课、你的课程样例/设想、套餐选择和风险边界。
