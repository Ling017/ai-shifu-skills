# 首次破冰和低成本信息收集

适用于用户因为发布会直播、直播宣传、朋友圈、社群、视频号、朋友推荐等渠道首次加微信。首轮目标不是销售，而是提高回复率、邀请进群、拿到最关键标签，并把后续联系主动权交给用户。

## 首轮目标

```text
邀请进直播/产品交流社群
-> 说明进群价值
-> 用低成本问题收集背景
-> 打上客群/进展/跟进标签
-> 告诉用户后续可私信或群内提问
```

## 核心原则

- 先邀请进群，说明价值：回放、资料、体验说明、答疑、重要信息同步。
- 首轮优先问 `背景/身份`，因为它直接决定销售分流；`来源渠道` 可顺带问，但不要作为核心首问。
- 用序号题降低回复成本，让用户只需回一个数字。
- 给 `先了解/不确定` 选项，避免用户因为没想清楚而不回复。
- 不要首条就问预算、人数、采购、套餐。
- 不要一上来发官网、案例、价格页、操作手册等多个链接。
- 每次只问一个主问题；用户愿意继续聊时，再问需求和 AI 程度。

## 信息优先级

```text
1. 背景/身份：他是谁
2. 需求方向：他为什么感兴趣
3. AI 使用程度：后续需要快速路径还是详细上手说明
4. 来源渠道：用于渠道归因和活动复盘
```

销售转化上，背景/身份优先于来源渠道。来源回答“从哪来”，背景回答“怎么跟”。

## 标签映射

| 用户信息 | 标签/字段 | 后续方向 |
|---|---|---|
| 老师/高校/中小学教学 | `客群-老师` | 备课、教学互动、减少答疑 |
| 课程创作者/知识付费/IP/训练营 | `客群-个人创作者` | 做课提效、课程交付、体验课、课程变现 |
| 教育机构/学校/学校服务商/教培机构 | `客群-教育机构` | 标准化交付、课程产品化、机构采购 |
| 企业培训/HR/内训/咨询乙方 | `客群-企业培训` | 新人培训、知识沉淀、企业采购、成本控制 |
| 先了解/不确定 | `客群-待确认` | 先进群培育，后续轻触达 |
| 想更快做课 | `需求-做课提效` | 后续推进首课体验 |
| 想让学员互动学习/追问 | `需求-提升交付` | 后续发示例课或推动学习地址验证 |
| 想减少答疑 | `需求-减少答疑` | 后续引导用高频问题/章节做样例 |
| 企业 SOP/产品手册/新人培训 | `需求-培训沉淀` | 后续引导用脱敏材料做企业试点 |
| 想招生/卖课/做体验课 | `需求-课程变现` | 后续引导体验章/课程包装 |
| 问价格/合同/发票/对公 | `需求-采购咨询` + `进展-套餐咨询` | 进入套餐判断 |
| 已加微信/已进群/已回复 | `进展-已沟通` | 继续低压跟进 |
| 首次触达未回复 | `进展-未回复` + `跟进-待唤醒` | 次日轻触达 |
| 企业/机构 + 需求明确 | `跟进-重点跟进` | 当天一对一跟进 |
| 背景明确但需求不强 | `跟进-后续跟进` | 3-5 天内继续推进 |
| 只进群/先了解 | `跟进-待培育` | 群内容、回放、低频触达 |

## 首次破冰结构

```text
欢迎
-> 说明来源
-> 邀请进群
-> 说明进群价值
-> 用序号题轻问背景
-> 告诉用户可随时私信/群内提问
```

首条最好只拿一个核心信息：`客群标签`。

## 首条话术：标准版

```text
你好，欢迎了解 AI 师傅。你应该是看到这次 2.0 发布会/直播宣传加过来的。

我先拉你进直播交流社群，后面发布会回放、产品资料、体验说明和答疑都会在群里同步，方便你不遗漏重要信息。

也轻问一下，方便后面有相关资料时更准确地同步给你。你更接近哪一类？回数字就行：

1）老师/高校/中小学教学
2）课程创作者/知识付费
3）教育机构/学校服务商
4）企业培训/HR/内训
5）先了解一下，还不确定
```

## 首条话术：短版

```text
你好，欢迎了解 AI 师傅。我先拉你进发布会直播交流社群，后面回放、资料、体验说明和答疑都会在群里同步。

也轻问一下，你更接近哪类？回数字就行：

1）老师
2）课程创作者
3）教育机构/学校
4）企业培训
5）先了解
```

## 顺带问来源

如果确实需要渠道归因，把来源放在首条末尾，不要放在最前面：

```text
如果方便，也可以顺手说下你是从视频号、朋友圈、朋友推荐，还是社群里看到我们的。
```

如果追求最高回复率，首条不问来源，先拿背景。

## 用户回复后的承接

### 1）老师

```text
收到，那我后面优先给你同步教学、备课、学生互动相关的信息。

你现在主要是先了解 AI 师傅，还是已经有一门课或一段教学资料想试试？
```

### 2）课程创作者

```text
收到，那你更像课程创作/知识付费场景。

你现在主要是想提升做课效率，还是想把课程做成可以互动学习、追问的交付形式？
```

### 3）教育机构/学校

```text
明白，那你这边更偏机构/学校场景。后面我会优先给你同步适合机构交付、课程标准化和体验课相关的信息。

你现在是先了解产品，还是已经有具体项目在看？
```

### 4）企业培训

```text
收到，那你更偏企业培训/内训场景。后面我会优先给你同步企业培训、知识沉淀、新人培训相关的信息。

你现在是先了解，还是已经有内部培训资料想看看能不能做成互动课？
```

### 5）先了解

```text
没问题，你可以先进群先看回放和资料。

后面如果你想体验产品、看操作说明，或者判断自己的场景适不适合 AI 师傅，随时私信我就行。群里有问题也可以直接问，我们看到会回复。
```

## 第二轮信息收集

用户愿意继续沟通时，再问需求和 AI 程度。

### 问需求

```text
我简单了解下你关注 AI 师傅的方向：你现在更偏向先了解产品，还是已经有具体的做课、教学、培训或交付需求？

不用写很完整，大概说一句就行。后面你也可以先进群看资料，有问题随时私信我或在群里问。
```

### 问 AI 程度

```text
再轻问一下，你平时用 AI 工具多吗？比如 ChatGPT、DeepSeek、豆包、Kimi 这类。

我主要是想判断后面给你发“快速体验路径”，还是更详细的上手说明。
```

## 用户不回复

不回复不是立刻放弃，也不是持续催促。先降低回复成本，再给低压入口，最后转入培育。

### 首次加微信后未回复：半天或次日

```text
我补充一下，你不用现在想得很清楚。先进群看回放和资料就可以。

如果方便，回个数字我后面好少打扰你、只发相关信息：

1）老师
2）课程创作者
3）教育机构/学校
4）企业培训
5）先了解
```

### 已邀群但没进群

```text
我再发你一次直播交流社群入口。后面发布会回放、产品资料、体验说明和答疑都会在群里同步。

你可以先进群先看，不需要马上沟通。有问题随时私信我或在群里问就行。
```

### 进群了但私聊不回复

```text
看到你已经进群啦，后面回放、资料和答疑会在群里陆续同步。

你可以先在群里看内容。如果后面想判断自己的场景适不适合 AI 师傅，或者想体验做一门小样例，随时私信我就行。
```

### 3 天后轻触达

```text
我轻轻同步一下，AI 师傅比较适合先用一小段资料体验，不需要一开始准备完整课程。

比如一页 PPT、一段讲义、一个知识点、一个常见问题，都可以先做成 5-10 分钟的小样例。

如果你后面想试，可以直接私信我，我发你体验路径。
```

### 7 天后低压收口

```text
我这边先不打扰你啦。你可以先在群里看回放和资料。

后面如果你想了解 AI 师傅怎么用于做课、教学互动、企业培训或课程交付，随时私信我就行，我再按你的场景给你建议。
```

### 重点线索不回复

企业、机构、老师、已发布课程、问过价格的人，不要太快放弃。换成更具体的轻触达：

```text
我补充一个点，像你这种企业/机构/教学场景，不一定要先做完整课程。更适合先拿一个小章节或一段资料跑样例，判断能不能用于真实交付。

如果你后面有具体资料想试，可以发我一句“想试”，我再给你最短体验路径。
```

## 不回复时的标签

| 情况 | 标签 |
|---|---|
| 第一次未回复 | `进展-未回复` + `跟进-待唤醒` |
| 进群但不私聊 | `进展-已沟通` + `跟进-待培育` |
| 3-7 天仍不回复 | `进展-未回复` + `跟进-待唤醒` |
| 14 天仍无回应 | `跟进-暂时放弃` |

## 首次接触记录字段

```text
来源渠道：视频号/朋友圈/朋友推荐/社群/其他/待确认
客群标签：老师/个人创作者/教育机构/企业培训/待确认
需求标签：做课提效/提升交付/减少答疑/培训沉淀/课程变现/采购咨询/待确认
AI 程度：高/中/低/待确认
进展标签：已加微信/已邀群/已进群/已沟通/未回复
跟进标签：重点跟进/后续跟进/待培育/待唤醒
最近沟通摘要：用户首次加微信，已邀请进群，已/未回复背景
下一步动作：等用户进群/根据背景分流/轻触达
```

## 错误示范

不要这样问：

```text
你有什么需求？
```

不要这样问：

```text
你预算多少？准备用多少人？要不要买套餐？
```

不要这样发：

```text
这是官网、价格页、案例、体验入口、操作手册，你都看看。
```

不要首句只问：

```text
你是从哪里看到我们的？
```

## 核心判断

```text
第一轮：邀请进群 + 序号题收集背景
第二轮：根据背景轻问需求
第三轮：用户愿意聊时，再问 AI 程度/具体资料/体验意愿
```

首次破冰最重要的标签是 `客群标签`，因为它决定后续分流、资料、话术和销售路径。
