# 案例打法库

用于把真实跟进过程沉淀成可复用打法。默认输出仍保持短：判断、核心动作、话术、下一步；只有用户要求时再展开标签、记录、套餐和完整策略。

## 案例：已发布课程但觉得还不够好

典型信号：

- 用户已经在后台生成并发布学习地址。
- 用户自己体验后认可这种形式，但觉得第一版课程还不够好。
- 用户可能想继续打磨，或担心自己做不出来高质量课程。

销售判断：

- 这是价值确认阶段，不是失败。
- 不要推动用户反复改课，也不要让用户继续做很多新课来证明能力。
- 关键是帮助用户理解：第一版不完美正常，课程质量提升需要 AI 理解、提示词能力、资料组织和时间打磨，这会在后续产品使用中完成。
- 15 天体验期的目标是确认“产品可以、用户可以、方向成立”，不是做出完美课程。

核心动作：

```text
肯定已跑通闭环 -> 对齐课程用途 -> 温和说明正式使用/付费后的支持和打磨空间 -> 询问下一步场景
```

短话术：

```text
很正常，第一版不用追求完美。你现在最重要的不是把这门课打磨到最终状态，而是已经验证了：你的内容可以被做成交互课，你自己也能跑通从资料到学习地址的闭环。

后面课程效果会随着你对 AI 的理解、提示词使用、资料整理和几轮打磨继续提升，这些本来就是正式使用过程中逐步完成的。

我建议你现在先判断这门课的用途：它更适合做儿童体验课、招生展示课，还是后续做成航空科普系列？如果方向成立，再看你适合用哪个套餐持续做和打磨。
```

可打标签：

```text
客群：客群-老师 / 客群-教育机构 / 客群-待确认
需求：需求-提升交付 / 需求-课程变现 / 需求-做课提效
进展：进展-已拿学习地址
跟进：跟进-重点跟进
```

不要做：

- 不要说“那你再继续改几版看看”。
- 不要要求用户继续做第二门、第三门来证明价值。
- 不要把体验期变成教学训练营，让用户不断发现自己不会。
- 不要激进报价，但也不要完全不提付费后的支持和正式使用价值。

## 案例：用户没参加直播但已在后台做课

典型信号：

- 用户没有听直播或没有看完整介绍。
- 但已经在后台生成课程，甚至发布学习地址。
- 课程有明确对象和主题，例如儿童游戏化教学、航空理论科普。

销售判断：

- 比只听直播但没行动的用户更值得跟进。
- 行为信号强：已经有内容、场景和上手意愿。
- 下一步不是补直播内容，而是基于其产出判断阶段和需求标签。

核心动作：

```text
确认已发布/已体验 -> 围绕产出问用途 -> 判断是否进入价值确认/套餐判断
```

短话术：

```text
我看到你已经自己做出了课程，这个比单纯听介绍更关键。说明你的内容和这个互动课形态已经有初步匹配。

下一步我建议不先回头补很多介绍，而是直接看这门课准备用在哪：是自己验证、给孩子体验、做招生体验课，还是后续做成系列课？

如果你已经发布了学习地址，也可以发我一下，我帮你从学习体验和后续使用方向上看一眼。
```

## 案例：用户认可形式但还没准备购买

典型信号：

- 用户说“这种形式特别好”“方向很好”“我先自己体验下”。
- 还没有问价格，或者没有明确采购计划。

销售判断：

- 这是正向信号，不能只回复“你再体验看看”。
- 需要把抽象认可转成下一步使用场景，但保持不激进。

短话术：

```text
太好了，你认可这种形式就很关键。接下来不用急着做很大，我更建议先判断它的正式用途：你是想自己继续验证，还是准备用来给孩子/学员体验，或者做成一个系列课程？

如果只是体验，先跑通一门就够了；如果准备持续使用，那后面就可以看适合哪个套餐，以及付费后怎么借助指导课和服务支持继续打磨。
```
