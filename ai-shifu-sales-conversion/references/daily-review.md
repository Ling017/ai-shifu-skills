# 每日复盘

用于每日销售同步、批量线索检查或漏斗诊断。

## 转化漏斗

```text
加微信 -> 已沟通 -> 已看案例/示例 -> 已注册 -> 已装 Skill -> 已生成课程 -> 已拿学习地址 -> 套餐咨询 -> 成交 -> 已成交服务
```

关键指标是 `已看案例/示例`、`已拿学习地址`、`套餐咨询/成交`，不只是注册。购买前不要要求用户邀请外部学习者验证。

## 15 分钟会议议程

| 时间 | 议题 | 产出 |
|---|---|---|
| 0-3 min | 昨日数据 | New leads, registered, Skill installed, generated, URL, viewed case/example, package consult, closed |
| 3-7 min | 重点线索 | S/A users, next action, owner, deadline |
| 7-10 min | 产品/技术卡点 | 问题、负责人、反馈时间 |
| 10-13 min | 资料/话术缺口 | What to create/update today |
| 13-15 min | 今日动作 | Each owner 1-3 concrete tasks |

## 批量输出格式

```text
重点跟进：
- 用户 / 标签 / 证据 / 下一步 / 负责人 / 截止时间

后续跟进：
- 用户 / 当前卡点 / 推进动作 / 下次跟进

待培育：
- 用户 / 缺什么认知 / 发什么内容

待唤醒：
- 用户 / 3-7-14 天节点 / 轻触达话术

已成交服务：
- 用户 / 开通状态 / 7 天动作 / 15 天动作 / 风险

需要升级：
- 用户 / 升级对象 / 原因 / 需要结果 / 截止时间

Skill 待更新：
- 新问题 / 有效话术 / 失败原因 / 需补资料
```
