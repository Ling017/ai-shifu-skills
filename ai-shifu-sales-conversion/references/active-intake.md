# 主动问询和输出规范

当用户只给出一句“这个线索怎么跟”“用户问价格怎么回”“我是运营该怎么回”时，先按本规范处理。

## 第一步：主动判断阶段

优先判断用户处于：

| 阶段 | 判断信号 | 本轮目标 |
|---|---|---|
| 初次接触 | 刚加微信、刚进群、只说了解一下 | 邀请进群，说明价值，用序号题低成本收集背景并打客群标签 |
| 需求判断 | 用户说做课、培训、答疑、变现等问题 | 确认客群和需求标签 |
| 案例/示例验证 | 用户不理解效果、怀疑有没有案例，或询问某行业案例 | 先挖背后顾虑，再发客户案例/示例课或引导自测 |
| 首课体验 | 用户想试、已注册、准备做课 | 推动用户自己用真实小材料做 5-10 分钟样例 |
| 发布验证 | 已生成课程但未发布 | 推动拿学习地址 |
| 价值确认 | 已发布、已体验、觉得好或觉得不够好 | 围绕已产出课程对齐用途和价值，不陷入无限打磨 |
| 套餐咨询 | 用户问价格、人数、权益 | 判断套餐方向 |
| 成交收口 | 用户想买、问付款/合同/发票/对公 | 给付款或采购下一步 |
| 客户成功 | 用户已付款 | 发指导课，推进第一门正式课 |
| 待唤醒 | 3 天以上未回复或停滞 | 轻触达，不刷屏 |

## 第二步：信息不足时怎么追问

最多问 3 个问题，且每个问题都要服务于下一步动作：

```text
我先确认 3 个信息，方便给你最短路径：
1）用户现在走到哪一步了？已沟通/已看案例/已注册/已拿学习地址/问套餐/已付款？
2）用户大概是什么类型？个人老师、教育机构、企业培训，还是其他？
3）现在卡点是什么？不理解效果、不会操作、问价格、要采购，还是买后使用？
```

## 第三步：信息不足也要给临时动作

```text
如果你暂时不确定阶段，建议先不要报价，也不要发一堆资料。先用一个低门槛问题接住用户，并根据回复再分流。
```

如果是发布会/直播/社群/朋友圈来源的首次加微信，优先读取 `references/first-contact-intake.md`。首轮不要急着给案例、建议或体验路径，先邀请进群并用序号题收集背景：

```text
你好，欢迎了解 AI 师傅。我先拉你进发布会直播交流社群，后面回放、资料、体验说明和答疑都会在群里同步。

也轻问一下，你更接近哪类？回数字就行：

1）老师
2）课程创作者
3）教育机构/学校
4）企业培训
5）先了解
```

临时通用话术：

```text
我先不发一堆介绍，先帮你判断最短路径。你现在更关心：1）怎么更快做课；2）学员怎么个性化学习和追问；3）企业/团队培训怎么沉淀；4）套餐和采购怎么选？你回一个数字就行。
```

## 第四步：默认短输出，必须可执行

处理单个线索时，默认不要输出完整销售表格，只给当前最核心的动作和话术：

- `判断`：一句话判断当前阶段。
- `核心动作`：本轮只推进一个动作。
- `话术`：一段可直接复制给用户的微信话术。
- `资料/下一步`：只给本轮必要资料或下次跟进点。
- `还需要我补`：询问是否需要标签、记录、套餐、升级、复盘或详细方案。

只有用户明确要求完整方案、批量复盘、采购推进、升级交接、成交收口或买后客户成功时，才展开更多字段。

## 第五步：避免低效输出

- 不只做分析，不给话术。
- 不只追问信息，不给临时动作。
- 不一次性给用户发所有资料。
- 不急着给建议、结论、链接或报价；先判断用户问题背后的真实顾虑。
- 不替用户做首课样例；首课体验必须引导用户自己上手，团队只提供文档、排障和生成后点评。
- 不默认输出一大堆标签、记录、风险、客户成功和全链路策略；先给本轮核心动作，再问用户还需要什么。
- 不让已发布课程用户一直改课或做新课；体验期主要证明产品可以、用户可以、方向成立。
