# 资料分发规则

不要一次性发送所有资料。只发送能推动用户进入下一节点的最小必要资料。

| 资料 | 链接/位置 | 适用场景 | 必须带上的下一步 |
|---|---|---|---|
| 产品体验后台 | https://app.ai-shifu.cn/admin | 用户想试试或准备注册 | “注册后用一份真实资料做首课” |

## 分发规则

| 用户状态 | 发送资料 | 不要做 |
|---|---|---|
| “想试试” | 体验后台 + 首课体验手册 + WorkBuddy/Skill 安装文档 | 不要只发官网；不要替用户做 |
| “不会操作” | WorkBuddy/Skill 安装文档 + 首课体验手册；必要时发课程版体验 | 不要一次性发多个长文档；不要因为对方没 AI 经验就代做 |
| 已注册但没有动作 | 发手册，并指向 Skill 安装步骤 | 不要继续讲概念 |
| 已安装 Skill | 发做课指令，要求用户自己选一个 5-10 分钟小材料生成 | 不要跳到价格；不要索要资料后替用户做 |
| 已生成但未发布 | 发布说明 | 不要把生成当成成功 |
| 已有学习地址 | 自己体验 + 客户案例/示例课 | 不要强迫用户购买前找真实学习者验证 |
| 企业/机构用户 | 发手册，并请用户准备 SOP/产品手册/核心章节 | 不要在试点前承诺定制方案 |
| 沉默用户 | 3/7/14 天唤醒话术 | 不要刷屏发长文档 |


## 基于证据的转化规则

不要把“邀请真实用户试学”作为购买前必经步骤。用客户案例和个性化学习示例课证明结果，帮助用户想象自己的产品/课程可以怎么做。购买后用课程创作指导课激活用户。

## 自助首课体验规则

首课体验要推动用户亲自上手，而不是由团队代做。第一次只需要一个 5-10 分钟的小材料，用户自己按 WorkBuddy 和课程创作 Skill 安装文档完成生成、上传、发布。团队可以做三件事：提供文档，卡点排障，生成后点评学习地址。用户犹豫或找不到资料时，先发个性化学习示例课降低理解成本，再回到“请你自己用一个小材料做样例”。

## 入口缺失时的处理

If a material is still an internal file or placeholder, do not pretend it is sendable. Say what is needed internally: “需要团队提供可外发链接/二维码/表单”. For the user, give the closest available link and keep the next action clear.
