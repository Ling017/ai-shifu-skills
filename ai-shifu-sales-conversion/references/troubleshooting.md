# 排障流程

出现技术问题时，先安抚用户并收集事实，再按需升级。

## 安抚话术

```text
这个问题我先帮你记录，不让你反复试错。麻烦你发我：截图、操作到哪一步、使用的设备和浏览器、账号信息。如果有课程链接/课程名也一起发我，我同步排查后给你下一步。
```

## 不同问题要收集的信息

| 问题 | 需要收集 |
|---|---|
| Skill 安装失败 | Screenshot, install command/page, account, browser, device |
| 授权失败 | Screenshot, account, operation step, error text |
| 课程上传失败 | File/link, size, format, screenshot, operation step |
| 发布失败 | 后台截图、课程名称/ID、报错文案 |
| 学习地址打不开 | URL, device, browser, network, screenshot, whether others can open |
| 模型互动异常 | Course URL, abnormal dialogue screenshot, expected answer, source material section |

## 销售处理

- If troubleshooting blocks a key lead, mark `跟进-重点跟进` and ask for same-day response.
- 如果用户只是轻度尝试，标记 `跟进-后续跟进`，承诺 24-48 小时内给下一步。
- After resolution, immediately push back to conversion milestone: publish URL or case/example-based package decision.
