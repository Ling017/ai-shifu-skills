# 线索阶段

用于判断线索所处阶段，并选择下一步动作。

| 阶段 | 信号 | 目标 | 下一步动作 |
|---|---|---|---|
| 初次接触 | 加微信、入群、留言“了解一下/想看看” | 接住并判断身份需求 | 问 3 个关键信息，不急着发长资料 |
| 需求判断 | 用户说做课慢、答疑多、机构/企业想用 | 打客群/需求标签 | 映射产品价值，选一个体验动作 |
| 首课体验 | 已愿意试、已注册、准备装 Skill | 用户自己进入真实做课 | 发体验入口、手册、WorkBuddy/Skill 安装文档，要求自己用 5-10 分钟小材料做课 |
| 生成课程 | 已装 Skill 或已生成内容 | 不停在“生成” | 推用户自己上传后台、预览、发布；卡住时排障但不代做 |
| 发布验证 | 已发布或接近发布 | 拿学习地址 | 要求发学习地址，自己学一遍 |
| 案例/示例验证 | 已有学习地址或仍在理解效果 | 用案例和示例课形成成交证据 | 发客户案例和个性化学习示例课，帮助用户理解自己的产品怎么做 |
| 套餐判断 | 问价格、权益、人数、采购 | 判断套餐路径 | 结合场景/人数/权益/采购流程收口 |
| 成交收口 | 要付款、合同、发票、对公、演示 | 推动明确决定 | 引导后台套餐页付款，或给采购下一步，必要时升级支持 |
| 客户成功 | 已付款 | 让客户用起来并产生结果 | 发购买后课程创作指导课，7 天首门正式课，15 天第二门课或上线计划 |
| 培育/唤醒 | 不回复、没资料、需求弱 | 保持低成本触达 | 3/7/14 天轻触达或群内容培育 |

Decision rules:

- If the user has not personally used real material, push self-service first-course experience before package deep dive.
- If the user has a learning URL, help them self-experience and compare with verified examples before generic product explanation.
- If the user understands the case/example value and asks price/procurement, treat as high priority.
