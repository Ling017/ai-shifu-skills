# AI 业务实战学习教练

面向业务人员，结合自己的项目学习 AI 业务落地、产品工程、数据与知识库判断。通过解释、示范与小尝试，帮助你说明选择理由、发现证据缺口，再推进任务。

## 开始使用

- “我想用 AI 改善团队答疑，带我判断该从哪里开始。”
- “我已有测试结果，帮我理解它能证明什么。”
- “从产品工程通识课第一节开始学习。”
- “结合刚才的问题，重新给我做一节个人课，并带我学。”

可以选择原课互动学习，也可以围绕自己的问题重新制作个人课；不必跳转平台才能继续获得帮助。主课 12 节支持完整本地学习，两门辅课提供方法参考和平台导航。个人课可选调用 ai-shifu-course-creator；缺少它也能在当前助理中继续带学，不会自动安装或发布课程。

## 安装与更新

需要支持加载 Skill 并读取参考文件的助理。导入完整 ZIP，或将解压后的 `ai-business-learning-coach` 文件夹放入宿主指定技能目录并重新加载；不能只复制 SKILL.md。没有 Skill 功能但能读取文件组的助理，可提供完整目录要求从入口开始，自动触发能力取决于宿主。

对外名称：AI 业务实战学习教练。技能标识：`ai-business-learning-coach`。正式版：1.0.0。前身为 `ai-business-product-engineering` 的 coach-v2.1-20260915 包。原平台课程名称与 ID 保持不变。

仅依赖支持 Skill 和本地文件读取的助理；不需要安装本项目的 Python 依赖。`scripts/check_package.py` 仅供维护者检查仓库完整性，使用 Python 3 标准库。

升级时用新包替换旧 Skill 的启用状态，避免两个名称同时被调用；不要删除包外学习记录。学习状态沿用 `.course-learning/ai-business-product-engineering/` 命名空间，或学员此前指定目录。目录归属不清先核对，不自动合并。新会话加载新规则；替换后请在宿主中刷新技能并开启新会话；旧会话可能仍保留旧规则。

## 学习记录与边界

记录有文件能力时保存在包外，没文件能力时用可复制摘要续课。平台与本地不自动同步；个人课、实战与主课进度分开。提供脱敏背景即可，没有项目可以用虚构例子。

本包帮助学习判断和共创材料，不执行部署、删除数据或外发消息。AI 起草不等于你已掌握；流程完成不等于实际业务效果。来源、版本与平台链接边界见 SOURCE.md。

## 仓库结构与维护

- `SKILL.md`：助理入口与按需读取路径。
- `coaching.md`、`personal-lesson.md`、`runtime.md`：实战、个人课与学习记录协议。
- `course.md`、`sections/`、`course-index.json`、`source-map.json`：原课正文与来源索引。
- `navigation.json`、`supplementary-navigation.json`：课程导航。
- `state-example.json`：空白结构示例，不含学员资料。

本目录可作为 GitHub 仓库根目录。提交前运行：

```bash
python3 scripts/check_package.py
```

检查不会联网或修改课程。修改教学规则时，用真实请求演练；修改来源正文时同步核对来源版本与指纹，不能只改校验值来掩盖来源变化。反馈问题请使用脱敏的最小对话，勿提交学习记录、客户资料、密钥或完整私人聊天。
