# Adaptive decision memo

Use only for a full decision request. Adapt/omit sections without invented content.

1. Decision first: outcome/status, actual mode and research coverage, target market, primary if defensible, reasons and uncertainty.
2. Reasoning: connect source capability, learner problem, buyer rationale, objective, and promise ceiling. Compare supported alternatives only.
3. Market evidence when researched: dated substitutes, demonstrated offers/limits, proposed substantive difference. Distinguish facts from inferred motives; state coverage gaps. No competitor minimum. In material-only mode state market unknowns rather than writing a simulated scan.
4. Teaching feasibility: show how knowledge, examples, practice, and feedback achieve the objective in the intended format. No lesson count threshold.
5. Decision and next step: actual risks, missing evidence, smallest useful validation. Price, MVP, score, growth forecast, and time-boxed plan only when useful.
6. Evidence appendix if needed: source locators, dated links, claim support, unknowns.

Use output-contract.md status mapping. No primary/backup/rejected-direction quotas. Reporting language and target geography are independent. Plans do not authorize interviews, publication, spending, or other external actions.
