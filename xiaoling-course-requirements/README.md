# Xiaoling 做课要求

`xiaoling-course-requirements` 是 Xiaoling 个人做课方法与 AI 协作要求的公开版，覆盖目标与内容、教学设计、差异化支持、提示词表达、课程测试和修改检查。供课程作者借鉴和明确采用，不作为所有老师的通用标准。

## 与其他 Skill 的关系

- 与 `ai-shifu-course-creator` 保持独立并联用。官方 Skill 提供通用设计能力、现行 MarkdownFlow 语法及平台操作；本 Skill 补充 Xiaoling 的教学判断和协作要求。官方 Skill 需从其维护渠道单独安装，本目录不包含其源码。
- 本仓库的 `ai-shifu-personalization-designer` 可用于提炼其他教师的方法；这里直接应用已经确认的个人要求，不要求每次重新访谈，也不与它合并。
- 本目录不依赖私人资料。缺少官方 Skill 时可做独立教学判断和文本工作，但不能声称已核对现行平台语法或完成平台操作。

## 使用

将本目录完整放入所用助手支持的 Skills 目录，保持 `SKILL.md`、`agents/` 与 `references/` 的相对位置。另行安装官方课程制作 Skill 后，可提出：

> 使用 $xiaoling-course-requirements，结合 AI 师傅课程制作 Skill，按这份材料优化教学设计，保留现有知识点。

> 使用 $xiaoling-course-requirements 测试课程，先问我最看重哪个方向，再进入对应测试。

若请求已明确测试方向（例如“只查事实错误和无法继续的硬伤，不修改”），直接沿用，不重复询问。可以单选或组合方向，不固定轮数；普通改稿自检不新增问答。

## 文件与边界

[SKILL.md](SKILL.md)是入口，按任务读取七份参考：全课设计、课节设计、方法选择、学习体验曲线、提示词表达与修改、课程测试、方法归属与证据边界。分类是职责，不是固定制作流程。
