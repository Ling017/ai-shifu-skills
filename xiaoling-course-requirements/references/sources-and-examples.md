# 方法归属、来源边界与示例

本公开版保留 Xiaoling 已确认的教学要求、协作方式与课程测试方法，不附私人原件、项目资料、学习记录、受限文档链接或本机路径。其他参考文件已包含执行所需规则，使用时不需要访问私人资料。

## 区分规则的身份

- 个人要求：Xiaoling 确认采用的目标表达、问题与任务起点、判断显化、完整案例、差异化支持、参与边界、提示词编辑与测试要求。保留“一般／有时／部分课程”等适用条件，不推广为人人必守的标准。
- 应用建议：将个人要求用于具体情境的设计选择，不自动视为已确认的普遍方法或效果结论。
- 方法候选：[方法选择](method-selection.md)中的技巧按目标选用，不全部归为 Xiaoling 独创，也不保证平台已实现。
- 项目选择：某门课的工具、学员前提、章节数量、售价与草稿状态仅约束该项目，不推广为通用规则。
- 外部方法：保留概念与方法归属，研究和效果主张应有可核实来源。完整通用教法与现行运行契约由单独安装的官方课程制作 Skill 维护。

## 个人教学判断的应用

将以下特点用于适合的任务，不要求每节全部出现：显化判断依据，从实际任务进入，按必要依赖安排成果台阶，用案例对照解释关键差别，诊断当前教学缺口，接受有依据的开放答案并保持明确标准。具体规则见[全课设计](whole-course-design.md)、[课节设计](lesson-design.md)与[方法选择](method-selection.md)。

[学习体验曲线](learning-experience-curve.md)用于节奏与支持分析，重点、难点、强体验和掌握证据分开。它是按需设计框架，不是精确测量工具或已经验证的统一理论。

## 示例与证据

本节是说明检查方式的假设示例，不是客户案例、项目记录或已验证效果：

| 假设情境 | 检查什么 | 可以与不可以作出的判断 |
| --- | --- | --- |
| 学员解释相关与因果 | 收齐判断与理由，对照材料回应 | 可判断本次推理；选中正确选项本身不足以证明理解 |
| 学员修改一份反馈稿 | 按同一标准复查最新完整稿，包括新错误 | 可描述帮助下修改；不能直接称为独立迁移或真实沟通改善 |
| 学员只看工具示范 | 完整交付讲解和必要结果，尊重参与方式 | 可说明展示了什么；不能声称其已安装、保存或完成外部工作 |
| 课程修复后跑通一个分支 | 用本次版本与输入核对等待、反馈和结束 | 可报告该路径观察；不能推为全课、所有入口或真人成效 |

新版本、新组合和不同输入需要自己的证据。没有运行记录时只作设计分析，不从假设示例、规则存在或旧版通过推定已有效。真实课堂、后台模拟、学员入口、外部操作、独立表现和真实效果分别报告。

## 维护边界

个人要求由 Xiaoling 明确确认后更新；应用建议、外部方法及单个失败先保留其条件与来源，不自动变成通用禁令。维护执行规则时不需要附私人项目资料，也不自动更改课程或配置。使用者若要采用其他作者的取舍，应明确调整，不仍称为 Xiaoling 已确认要求。
