# 方法选择与教学动作

这是条件性方法索引，不是人人必走的流程。手册新增技巧是设计候选，不全部等于 Xiaoling 已确认个人方法或已实现平台能力。来源与案例见 [sources-and-examples.md](sources-and-examples.md)。以下索引保留选择线索及关键教学动作，不另建通用教学手册。官方 Skill 的 teaching-design.md、prompt-semantics.md 负责完整方法指导、取舍与运行授权边界；选中相关方法时按需读取。表中的动作仅在该方法和活动已选用时适用，不构成所有课程的要求。

## 选择依据

从目标和实际表现判断主要卡点；证据不足时保留教学假设。选一个有用的主方法及必要辅助，说明学生亲自做什么、支持如何改变、怎样检查与结束。不把方法名称当作设计完成，也不机械填满机制链。

“教学、单点练习、综合应用”用于查找，不构成顺序。认知课可以讲授为主，互动、练习和成果依目标选择。工作框架如 GROW、SBI、SPIN 与教学安排区分：框架规定学什么，示范、提问、角色扮演与反馈帮助学会它。

## 教学

| 当前困难／目标 | 可选方法与应保留动作 |
| --- | --- |
| 陌生概念需要理解 | 准确定义与必要条件，再用熟悉例子或类比映射关系、说明差异；背景不足用中性例子，类比不作证明。可纯讲授，不必收答。 |
| 只记一个例子或混淆边界 | 比较正反例、不同表象或变化条件，指出决定性关系；不为制造反差贬低合理理解。 |
| 实际理由暴露误区 | 收齐所需判断与理由，针对真实推理纠偏；不凭选项猜心理，首答充分不强迫承认错误或重走纠偏。 |
| 不会做或不会判断 | 展示完整用法及结果，显化选择依据与自检；示范前说明观察重点。必要时以补全任务和范例渐隐接向独立应用。 |
| 已有基础但缺问题感 | 可低代价先探索，再针对暴露问题整合解释；生产性失败不等于不给必要支持。 |
| 解释不清或观点含糊 | 费曼式任务让学生面向明确新手亲自解释，按准确性补缺并等待重讲；苏格拉底围绕实际立场的定义、证据和假设选下一问，允许有理保留观点，清楚后结束。 |

## 单点练习与反馈

| 场景 | 必要动作与边界 |
| --- | --- |
| 诊断 | 观察相关实际过程或少量针对任务，区分知识、前提、审题、策略与条件；诊断后接回教学。自报信心不替代表现。 |
| 递进提示 | 先尝试，卡住时给一条相关线索，等待新尝试后决定是否加帮助。必要时补基础，再回原题或等价任务；记录帮助经历。 |
| 可行动反馈／改稿 | 按目标明确有效处、关键缺口和可改动作；优先当前最重要问题。等待实际新稿，用同一标准检查完整最新稿，包括新错误。必要修正与可选建议分开；不能标准扩张或一边判通过一边要求必要修正。 |
| 连续答题 | 轮内收齐作答且不揭答；轮末以同一实际记录核对逐题结果、总分、错题集合。保留原题身份与标准，仅重练仍错题。自然语言不保证精确计分，不得偷偷嵌程序后宣称模型计分可靠。 |
| 迁移／复习 | 按目标选择变式、交错、提取、间隔或累积任务。新题先独立尝试，保留提示记录；同题订正、近迁移和延迟保持分别判断。不默认有计时、调度与提醒。 |

外部实践支持与课堂练习分开，遵循[参与方式与外部实践](lesson-design.md#参与方式与外部实践)；下列项目、排障等方法不能据此启动实践成果验收。

## 综合应用与条件检查

- 岗位带练：给定岗位目标、人物事实、权限和行为标准；对方承接实际表达。客户角色与教练明确切换，必要时暂停、提示、重练关键回合再返回角色。授权范围内可生成情境，但不能用任意新事实改变判断、提前透露待探查信息或许诺价格服务。模拟接受不证明真实成交。
- 教练式引导：澄清具体事件、事实／推断、目标和限制，帮助提出比较选项，由学员作决定。假设贯穿标明；不代决策，也不把自选行动设计写成已执行。
- 项目实践：有真实用途，保留必要前提后形成小样，有稿从修改进入；卡点处补知识后回同一任务。完整 PBL 还需相应探究、选择、修订和真实检验，不把任意作品或流程称作完整 PBL。
- 软件排障：先用已有目标与现象，缺信息时只补会改变帮助的环境、操作、脱敏报错或最小相关输入／输出片段，不默认收齐全文、日志或截图。分开表述已观察现象、候选原因与排查建议；单个错误码或换目标仍失败不能直接证明具体原因。可给小范围排查建议，由本人按实际条件决定；不要求回报结果以证明完成。学生文字报告不等于 AI 自动读屏、执行或验证。
- 仿真探究：明确模型、条件与探索目的，按需预测、控制变量、比较、解释；实际页面操作和 AI 可读课程提交区分。不强加文字回答模拟其他方法，不假设页面事件进入课程记忆。
- 语言训练：按实际水平提供必要输入，围绕沟通目的回应与再次表达；区分沟通完成与语言质量。发音、听辨需真实音频。
- 团队／同伴：共同成果之外检查个人理解和贡献；真实协作需要信息或决策相互依赖。AI 模拟同伴须标明，团队分数不证明个人掌握。
- 动作技能：需要真实过程或适当记录及具备条件的教师／专业人员观察，文字自述不能替代动作证据。

## 停止、归因与验证

练习的标准和边界来自目标、时间条件及作者要求，不固定次数。已达标及时结束；停滞时换支持，停止或跳过按作者条件处理且不伪造通过。不因展示方法而追加题目、承诺或确认。

区分题目及必要条件与作答后的额外解题线索，依据真实帮助经历报告表现。AI 完成的部分不计为学生独立表现。检验所选方法的特有动作，例如等待新尝试、整轮隐去答案、角色切换、完整稿复查和回原任务；不能只检查有问答和总结。
