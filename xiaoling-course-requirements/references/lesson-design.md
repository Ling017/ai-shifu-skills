# 课节设计

负责本节目标、知识和案例组织、判断讲解、背景适配与图文。所选方法的动作、反馈时机和停止条件见 [method-selection.md](method-selection.md)，可执行表达见 [prompt-writing-and-revision.md](prompt-writing-and-revision.md)。

## 从问题进入知识

让学员知道此时为什么学、与自己有什么关系。优先使用已知任务、经历、输入与结果；已有明确问题直接进入，不每节重访谈或重找痛点。无经历可用背景完整且标明的例子；当前做法合理不制造错误。

区分真实困扰与术语：既不把每个经验都教成概念分类，也不因避免概念化而弱化问题。讲清当前需要的知识和应对办法，不展开无关百科。

## 案例、解释与判断

- 提供无需参加原讨论也能理解的角色、目标、材料、约束和问题。不只删除“直播里”等字样，却留下不明指代。
- 示范需要完整时，展示任务、必要材料、处理、结果与关键判断。解释看见了什么、为什么选、何时换、怎样自检；不能只展示好看的成品。
- 逐项核对知识与案例中的可见变化：所称改进必须真的发生，并能解释所学方法。换行业称呼不等于适配。
- 对比保留同一事实与质量标准；不新增原材料没有的政策、数值、原因和承诺制造效果。未知不写成没有，建议不写成决定，采用不写成实际执行。
- 概念定义保留必要条件；类比、故事和通俗表达不能替代准确含义。讲解深度按任务与起点确定，简洁不等于省略推理。
- 合成／改编材料不冒充真实客户、教师经历或学员原始输入。示例不能覆盖学员自己的项目。
- 完整教学示范可同时给原文和结果解释动作；真实实践请求与示范材料分开，只填本人任务所需材料、源位置、用途和目标。不将请求自带的原文或预期答案被复述，当成已读取指定外部资料的证据；实践是否合用仍由学员自行确认。

## 参与方式与外部实践

分别判断是否愿意课堂思考、是否愿意在外部工具操作，不用一个“愿不愿实践”合并两者。

- 明确只看或不答题：完整交付必要讲解、材料与示范，不再询问参与方式，不追加选择题、练习或操作作业。
- 愿意课堂参与但不外部操作：可讨论自己的材料、判断或模拟稿，按课堂标准给线索与反馈；不自动降为只看，也不转成安装、保存或交回成果的任务。
- 愿意外部实践：说明可以看到什么预期结果、怎样在自己环境确认；不要求贴原文、输出、文档、路径、截图或运行记录来验收，不发“完成了吗／是否成功”确认题，不等待成果后才继续。学员表示没问题、已完成或暂不操作即可自然收束，不据此宣称目标已达成。
- 主动报告卡点：先回应已给现象；必要时只补直接影响帮助的最少脱敏信息或相关片段。不启动整份成果审查，不重复索取已提供内容，不为证明完成而要求重试或重新授权。

教师示范、课堂模拟和本人外部实践分别标明。无可读证据时，不按课序说“你已经保存／安装／完成了上一节”；用“如果已有可用方法”或完整教师示例衔接。已有本次模拟原文、稿件或问题就优先采用，不绕开它另编同类错误；提供过材料不等于做过外部操作。

## 个性化

依据已有任务、相关经验、当前回答和作品，选择适当例子、解释与支持。说明哪些信息改变什么教学动作；无相关背景用中性回退，只在必要且允许时补问关键缺口。

背景偏好可以选择局部讲解入口，不证明熟练程度；实际回答优先于静态身份假设。保持目标、事实、标准及作者固定内容，不能泛授权授课 Agent 自由重做课程。

## 图文配合

图用于关系、过程、比较、导航、任务材料或操作支持，文字发展理由和应用，不仅重复标签。是否用静态图、渐进展示或交互，按目标与真实交付能力选择。

保留可复制使用的任务要求与关键材料，不仅放进图片。图中答案不能提前破坏要观察的独立判断；实际回答入口清晰，不用画出的选项或输入框冒充交互。

方法展示训练可先说明练什么、如何帮助，但不把这种开场推广到所有课。全课统一视觉要求放课程提示词，具体图示位置、内容、目的与图文关系放授课提示词。固定图数、卡片、表格只在有依据或作者要求时使用。

## 局部检查

确认本节知识足够支持目标，例子能独立理解且与讲解对应，学员亲自做的判断未被代替，支持与呈现没有增加无关负担。审查时分清缺陷、建议和无法评估项。专门测试课程时，依[课程测试方法与要求](course-quality-review.md)确定方向、选取路径和报告证据；局部自检不自动扩成全课测试。
